# Glossary

| Term | Definition |
| --- | --- |
| Survey | One configured form and its related submission/results code. |
| Response | A single respondent's saved answers in a survey's SQLite database. |
| Results hub | `survey/results.php`, where an administrator selects a survey to view or export. |
| Targeted package | ZIP created with `tools/build-package.py --survey <slug>`; includes code for one survey and shared runtime, not database files. |
| Local XAMPP | The local development environment used before any hosted deployment. |
